# OndasContinuas


Aplicación de browser para la síntesis de sonido controlado por código javascript.

Utilidad creada para explorar texturas sonoras y drones medante la síntesis digital de audio.

Ofrece funciones básicas para controlar parámetros como volumen, paneo, frecuencia, tipo de onda, fundidos, modulación de frecuencia, modulación de anillo.


## Requerimientos
- Python >= 3.9
- Browser moderno
